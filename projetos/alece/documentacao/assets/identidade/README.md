# Identidade visual

- `favicon_original.svg`: **logomarca/favIcon original sem alterações**, extraída de `docs-alece/portifolio/favicon.svg` do arquivo fornecido.
- `logo_horizontal_derivado.svg`: composição vetorial para capa técnica, derivada das mesmas formas e cores; **não substitui automaticamente** o logo oficial do produto.
- `interface_alece_referencia.webp`: captura original do site de apresentação.
- `mapa_financeiro_original.jpg`: diagrama entregue pelo autor, preservado.

Não há fontes tipográficas distribuídas. O HTML da apresentação original contém o wordmark em texto estilizado, não um `logo.svg` separado.
